# ST-LifeSim

**SillyTavern용 생활 시뮬레이션 확장 프로그램**

ST-LifeSim은 SillyTavern에 다양한 생활 시뮬레이션 기능을 추가하는 확장 프로그램입니다.
이모티콘, NPC 연락처, 통화, 지갑, SNS, 캘린더 등의 기능을 제공하여 더욱 풍부하고 몰입감 있는 롤플레이 경험을 제공합니다.

## ✨ 주요 기능

### 📦 모듈 목록

#### 1. 😊 이모티콘
- 커스텀 이모티콘 URL 등록 및 관리
- 카테고리별 분류 및 검색
- 즐겨찾기 기능
- AI 사용 가능/불가 설정
- 채팅에서 클릭 한 번으로 전송

#### 2. 📋 NPC 연락처
- 주변 인물 상세 정보 관리
- 프로필 이미지, 관계, 성격 등록
- {{user}} 및 {{char}}와의 관계 설정
- 태그 기반 검색
- 자동 컨텍스트 주입으로 AI가 인물 인식

#### 3. ⚡ 퀵 도구 모음
- **퀵센드**: AI 응답 없이 메시지 전송 (Ctrl+Shift+Enter)
- **시간 구분선**: 시간 경과 표시 (30분 후, 1시간 후 등)
- **읽씹**: 읽음 표시 후 AI 반응 생성
- **연락 안됨**: 연결 실패 상황 연출
- **사건 생성**: 7가지 카테고리의 랜덤 이벤트 생성
- **사건 기록**: 발생한 사건 아카이브 및 컨텍스트 관리
- **음성메모**: 음성 메시지 연출 (길이 및 힌트 설정)

#### 4. 📞 통화 & 통화기록
- AI 응답에서 통화 키워드 자동 감지
- 통화 시작/종료 알림
- 실시간 통화 타이머
- 통화 내용 아카이브
- 부재중 전화 기능
- 컨텍스트 포함/제외 설정

#### 5. 💰 지갑 & 송금
- 커스텀 화폐 이름 및 기호 설정
- 잔액 충전/차감
- 연락처로 송금
- 거래 내역 관리
- 채팅에 영수증 자동 전송

#### 6. 📸 SNS 피드
- 일반 게시물 및 스토리 작성
- AI 랜덤 포스팅 (20% 확률, MESSAGE_RECEIVED 시)
- {{char}} 및 NPC들이 자동으로 포스팅
- 좋아요 및 댓글 시스템
- AI 자동 답글 생성
- 최근 게시물 컨텍스트 주입

#### 7. 📅 캘린더
- 1~30일 순환 시스템 (월 개념 없음)
- 날짜 앞뒤 이동
- 일정 추가/편집/삭제
- 연락처 연동
- 일정 완료 체크
- 오늘 및 다가오는 일정 컨텍스트 주입

## 🚀 설치 방법

### 자동 설치 (권장)

1. SillyTavern을 실행합니다.
2. 상단 메뉴에서 **Extensions** > **Install Extension** 클릭
3. GitHub URL 입력: `https://github.com/gulggu/STP`
4. **Install** 버튼 클릭

### 수동 설치

1. 이 저장소를 다운로드하거나 클론:
   ```bash
   cd [SillyTavern 폴더]/public/scripts/extensions/third-party
   git clone https://github.com/gulggu/STP.git st-lifesim
   ```

2. SillyTavern을 재시작

3. 확장이 자동으로 로드됩니다.

### 설치 확인

- 채팅 입력창 근처에 **⚙️ ST-LifeSim** 버튼이 표시되면 설치 완료
- 툴바에 각 모듈 버튼들이 나타남

## 📖 모듈 상세 가이드

### 😊 이모티콘

**기본 사용법:**
1. 툴바에서 **😊 이모티콘** 버튼 클릭
2. 원하는 이모티콘 클릭하여 전송

**이모티콘 추가:**
1. **+ 이모티콘 추가** 버튼 클릭
2. 이름, URL, 카테고리 입력
3. AI 사용 가능 여부 선택
4. **저장** 클릭

**팁:**
- 즐겨찾기 탭에서 자주 쓰는 이모티콘 빠르게 접근
- AI 사용 가능 이모티콘은 컨텍스트에 자동 주입되어 AI도 사용 가능
- 우클릭으로 즐겨찾기 추가/편집/삭제

---

### 📋 NPC 연락처

**연락처 추가:**
1. 툴바에서 **📋 연락처** 버튼 클릭
2. **+ 새 연락처** 클릭
3. 필수 정보 입력:
   - 이름
   - 한줄 소개
   - {{user}}와의 관계
4. 선택 정보:
   - 프로필 이미지 URL
   - {{char}}와의 관계
   - 성격/말투
   - 전화번호
   - 태그

**컨텍스트 주입:**
- 등록된 모든 연락처가 자동으로 컨텍스트에 포함
- AI가 인물을 인식하고 자연스럽게 언급 가능
- "홍길동에게 연락해봐"와 같은 대화 가능

**저장 방식 전환:**
- 하단에서 **이 채팅** / **이 캐릭터** 선택
- 캐릭터별 저장: 같은 캐릭터의 모든 채팅에서 동일한 연락처 유지

---

### ⚡ 퀵 도구 모음

**퀵센드 (📨):**
- 단축키: `Ctrl+Shift+Enter`
- AI 응답 없이 메시지만 전송
- 독백, 행동 묘사 등에 활용

**시간 구분선 (⏱️):**
- 클릭 후 시간 선택
- 시간 경과를 명확하게 표시
- 커스텀 시간 입력 가능

**읽씹 (👻):**
- 읽음 표시 후 AI가 읽씹 상황 묘사
- 긴장감 있는 상황 연출에 활용

**연락 안됨 (📵):**
- 연결되지 않는 상황 자동 생성
- 캐릭터가 응답하지 않는 시나리오

**사건 생성 (⚡):**
- 7가지 카테고리 중 선택:
  - 📰 일상 / 💼 직장/학교 / ❤️ 관계
  - 🌧️ 사고 / 🎉 좋은일 / ⚡ 긴급 / 🎲 랜덤
- AI가 현재 상황에 맞는 사건 생성
- 사건 기록에 자동 저장

**사건 기록 (📜):**
- 생성된 모든 사건 확인
- 컨텍스트 포함/제외 토글
- 중요한 사건만 선택적으로 AI에게 알림

**음성메모 (🎤):**
- 음성 메시지 길이(초) 입력
- 선택적으로 내용 힌트 입력
- 힌트가 있으면 AI가 내용에 반응

---

### 📞 통화 & 통화기록

**자동 통화 감지:**
- AI가 "전화할게", "전화 걸게" 등의 키워드 사용 시 자동 감지
- 알림 팝업 표시
- **확인** 클릭으로 통화 시작

**통화 중:**
- 우측 하단에 통화 타이머 표시
- 일반 채팅 계속 가능
- **📵 통화 종료** 버튼으로 종료

**통화 종료 후:**
- 통화 시간 자동 계산
- 통화 기록 저장 여부 선택
- 저장 시 통화기록 패널에서 확인 가능

**부재중 전화 (📵):**
- 툴바에서 **📵 부재중** 클릭
- 연락처 선택 및 횟수 입력
- 연락이 안 되는 상황 연출

**통화기록 관리:**
- **📞 통화기록** 버튼으로 전체 기록 확인
- 연락처별 탭으로 필터링
- 컨텍스트 포함/제외 설정

---

### 💰 지갑 & 송금

**초기 설정:**
1. **⚙️ 설정** 버튼 클릭
2. 화폐 이름 설정 (예: 원, 골드, 크레딧)
3. 화폐 기호 설정 (예: ₩, G, ¢)

**잔액 관리:**
- **+ 충전**: 잔액 추가 (월급, 수입 등)
- **- 차감**: 잔액 차감 (지출 등)
- 메모를 입력하여 거래 이유 기록

**송금:**
1. 받는 사람 선택 (연락처 목록에서)
2. 금액 입력
3. 메모 입력 (선택)
4. **송금 확인** 클릭
5. 채팅에 영수증 자동 전송

**거래 내역:**
- 모든 입출금 내역 확인
- 날짜, 금액, 잔액 표시
- 거래 상대 및 메모 확인

---

### 📸 SNS 피드

**직접 게시물 올리기:**
1. **✏️ 직접 올리기** 클릭
2. 내용 작성
3. 선택적으로 이미지 URL 입력
4. 일반 게시물 또는 스토리 선택
5. **올리기** 클릭

**AI 랜덤 포스팅:**
- AI 응답 후 20% 확률로 자동 발동
- {{char}} 또는 연락처 NPC 중 랜덤 선택
- AI가 해당 인물 성격에 맞는 포스팅 생성
- 채팅에 알림 표시

**수동 NPC 포스팅:**
- **🎲 NPC 포스팅** 버튼으로 즉시 발동
- 테스트나 특정 시점에 유용

**댓글 및 답글:**
- 게시물 하단 **💬 댓글** 버튼 클릭
- 댓글 입력 후 **달기**
- NPC 게시물에 댓글 시 AI가 자동으로 답글 생성

**피드 관리:**
- **피드** 탭: 일반 게시물
- **스토리** 탭: 24시간 제한 스토리
- 좋아요 클릭으로 반응
- 불필요한 게시물 삭제 가능

---

### 📅 캘린더

**날짜 시스템:**
- 1일부터 30일까지 순환
- 월(Month) 개념 없음
- 오늘 날짜는 수동으로 설정

**날짜 이동:**
- **◀** 버튼: 하루 전으로
- **▶** 버튼: 하루 후로
- 달력에서 날짜 클릭으로 직접 이동

**일정 추가:**
1. **+ 일정 추가** 버튼 클릭
2. 날짜 선택 (1~30)
3. 시간 입력 (선택)
4. 제목 및 내용 입력
5. 관련 인물 선택 (선택)
6. **저장** 클릭

**일정 관리:**
- 완료 체크: **완료** 버튼으로 완료 표시
- 편집: **편집** 버튼으로 수정
- 삭제: **삭제** 버튼으로 제거

**컨텍스트:**
- 오늘의 일정 자동 주입
- D+7까지의 다가오는 일정 표시
- 완료된 일정은 컨텍스트에서 제외

## 📐 핵심 설계 원칙
### 모듈화 아키텍처
- 각 기능은 독립된 모듈로 구성
- 모듈별 개별 ON/OFF 가능
- 하나를 꺼도 다른 기능에 영향 없음

### 데이터 저장소
- **채팅별 저장**: 각 채팅방마다 별도 데이터
- **캐릭터별 저장**: 같은 캐릭터면 모든 채팅에서 공유
- 항목 단위로 전환 가능

### 컨텍스트 주입 시스템
- World Info 대신 직접 프롬프트 주입
- 모든 모듈 정보를 하나의 블록으로 통합
- 모듈 OFF 또는 데이터 없으면 섹션 생략 (토큰 절약)
- 매 메시지 전송 전 자동 주입

### 슬래시 커맨드 활용
- `/send`: 유저 메시지 전송 (AI 응답 없음)
- `/sendas`: 특정 캐릭터로 메시지 전송
- `/echo`: 시스템 알림 메시지
- `/gen`: AI 응답 생성 후 전송

## 💡 사용 예시

### 시나리오 1: 일상 대화에서 연락처 활용

```
User: 오늘 홍길동이 생일이라는데 뭐 선물할까?
AI (컨텍스트에 홍길동 정보 포함): 
  홍길동... 네 소꿉친구 맞죠? 그 친구 게임 좋아하지 않았나요?
  
User: [지갑 열기 -> 송금 50,000원 -> "생일 축하"]
  [채팅에 영수증 자동 전송]
```

### 시나리오 2: 통화 상황 연출

```
AI: 잠깐만요, 전화 한 통만 받고 올게요.
  [자동으로 통화 알림 팝업]
  
User: [확인 클릭]
  [채팅]: 📞 통화 시작 — {{char}}
  [우측 하단에 타이머 표시: 00:35]
  
User: [대화 계속...]
  
User: [📵 통화 종료 클릭]
  [채팅]: 📵 통화 종료 (통화시간: 2분 17초)
  [저장 확인 팝업]
```

### 시나리오 3: SNS 인터랙션

```
AI: [응답 완료]
  [20% 확률로 자동 발동]
  [채팅]: 📸 홍길동님이 새 게시물을 올렸습니다.
  
User: [📸 SNS 열기]
  [피드]: "오늘 커피 맛집 발견! ☕ #데일리 #카페투어"
  
User: [댓글 입력] "어디야? 나도 가고 싶다"
  [채팅]: [홍길동의 게시물에 댓글] 어디야? 나도 가고 싶다
  
  [2초 후 AI 자동 답글]
  홍길동: "강남역 2번 출구 쪽! 같이 갈래?"
```

### 시나리오 4: 일정 관리

```
User: [📅 캘린더 열기]
  오늘: 15일
  
User: [+ 일정 추가]
  날짜: 18일
  시간: 14:00
  제목: {{char}}와 영화 데이트
  관련 인물: {{char}}
  
AI: [컨텍스트 자동 주입]
  "아, 18일에 영화 보기로 했죠? 기대되네요!"
```

### 시나리오 5: 사건 생성으로 스토리 전개

```
User: [⚡ 사건생성 -> 🌧️ 사고 선택]
  
AI: [생성된 사건]
  "갑자기 비가 억수같이 쏟아지기 시작했다. 
  우산도 없이 나온 당신은 황급히 근처 카페로 뛰어들었다."
  
User: 아, 비 오는 거 몰랐는데...
  
AI: [상황에 맞춰 반응]
  "괜찮아요? 옷 다 젖었네요. 여기 앉아서 잠시 쉬어요."
```

## 🔍 문제 해결 (Troubleshooting)

### 확장이 로드되지 않아요
- SillyTavern을 재시작해보세요
- 브라우저 콘솔(F12)에서 에러 메시지 확인
- 파일 경로가 올바른지 확인: `public/scripts/extensions/third-party/st-lifesim/`

### 버튼이 표시되지 않아요
- 설정 패널에서 해당 모듈이 활성화되어 있는지 확인
- 페이지를 새로고침(F5)해보세요

### AI가 컨텍스트를 인식하지 못해요
- 설정 패널에서 현재 컨텍스트 토큰 수 확인
- 모듈이 활성화되어 있고 데이터가 입력되어 있는지 확인
- SillyTavern의 컨텍스트 설정이 올바른지 확인

### 데이터가 사라졌어요
- 저장 방식(채팅별/캐릭터별)을 변경했는지 확인
- 다른 채팅이나 캐릭터로 전환했는지 확인
- 백업 기능을 사용하여 정기적으로 데이터 백업 권장

### AI 랜덤 포스팅이 작동하지 않아요
- SNS 모듈이 활성화되어 있는지 확인
- 브라우저 콘솔에서 이벤트 등록 로그 확인
- 20% 확률이므로 여러 번 시도해보세요

## 🔧 사용 방법

### 기본 설정

1. **설정 패널 열기**
   - 채팅 입력창 근처의 **⚙️ ST-LifeSim** 버튼 클릭

2. **모듈 활성화/비활성화**
   - 설정 패널에서 각 모듈 체크박스를 선택/해제
   - 변경 사항은 **설정 저장** 버튼으로 적용

3. **컨텍스트 토큰 확인**
   - 설정 패널 하단에서 현재 컨텍스트 토큰 수 확인
   - 불필요한 모듈은 비활성화하여 토큰 절약

4. **데이터 관리**
   - **데이터 백업**: 모든 데이터를 JSON 파일로 저장
   - **데이터 복원**: 백업 파일에서 데이터 불러오기

### 저장소 바인딩

각 모듈의 데이터는 두 가지 방식으로 저장 가능:

- **채팅별 저장** (기본): 각 채팅방마다 독립된 데이터
- **캐릭터별 저장**: 같은 캐릭터면 모든 채팅에서 공유

※ 연락처, 지갑 등 모듈마다 개별 설정 가능
