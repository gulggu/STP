# ST-LifeSim

SillyTavern용 생활 시뮬레이션 확장 프로그램

## 📋 개요

ST-LifeSim은 SillyTavern에 다양한 생활 시뮬레이션 기능을 추가하는 확장 프로그램입니다.
이모티콘, NPC 연락처, 통화, 지갑, SNS, 캘린더 등의 기능을 제공하여 더욱 풍부한 롤플레이 경험을 제공합니다.

## ✨ 주요 기능

### 📦 모듈

1. **😊 이모티콘** - 커스텀 이모티콘 등록 및 전송
2. **📋 NPC 연락처** - 주변 인물 관리 및 자동 컨텍스트 주입
3. **⚡ 퀵 도구 모음** - 퀵센드, 시간 구분선, 읽씹, 연락안됨, 사건 생성, 음성메모
4. **📞 통화 & 통화기록** - 통화 자동 감지 및 아카이브
5. **💰 지갑 & 송금** - 커스텀 화폐 시스템
6. **📸 SNS 피드** - AI 랜덤 포스팅 및 댓글/답글 시스템
7. **📅 캘린더** - 1~30일 순환 시스템

## 🚀 설치 방법

1. SillyTavern의 `public/scripts/extensions/third-party` 폴더에 이 저장소를 클론하거나 다운로드합니다.
2. SillyTavern을 재시작합니다.
3. 확장이 자동으로 로드됩니다.

## 📐 핵심 설계

### 모듈화 구조
- 각 기능은 독립된 모듈로 구성
- 모듈별 개별 ON/OFF 가능
- 하나를 꺼도 다른 기능에 영향 없음

### 저장소 시스템
- **채팅별 저장**: 각 채팅방마다 별도 데이터
- **캐릭터별 저장**: 같은 캐릭터면 모든 채팅에서 공유
- 항목 단위로 전환 가능

### 컨텍스트 주입
- World Info 대신 직접 프롬프트 주입
- 모든 모듈 정보를 하나의 블록으로 통합
- 모듈 OFF 또는 데이터 없으면 섹션 생략 (토큰 절약)

## 📁 프로젝트 구조

```
st-lifesim/
├── index.js                  # 진입점
├── manifest.json             # 확장 메타정보
├── style.css                 # 공통 스타일
├── settings.js               # 설정 관리
├── modules/                  # 각 기능 모듈
│   ├── emoticon/
│   ├── contacts/
│   ├── quick-tools/
│   ├── call/
│   ├── wallet/
│   ├── sns/
│   └── calendar/
└── utils/                    # 공통 유틸리티
    ├── storage.js            # 저장소 관리
    ├── context-inject.js     # 컨텍스트 주입
    ├── slash.js              # 슬래시 커맨드 래퍼
    ├── popup.js              # 팝업 컴포넌트
    └── ui.js                 # 공통 UI
```

## 🔧 사용 방법

### 설정 패널
채팅 입력창 근처의 "⚙️ ST-LifeSim" 버튼을 클릭하여 설정 패널을 엽니다.

### 모듈 활성화/비활성화
설정 패널에서 각 모듈을 개별적으로 활성화하거나 비활성화할 수 있습니다.

### 데이터 백업/복원
설정 패널에서 데이터를 JSON 파일로 백업하거나 복원할 수 있습니다.
