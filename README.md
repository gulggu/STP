# 🎮 ST-LifeSim - SillyTavern Life Simulation Extension

**상태**: Phase 1-2 완료 - 기반 구조 및 핵심 입력 도구 구현

SillyTavern용 라이프 시뮬레이션 확장 프로그램으로, 이모티콘, NPC 연락처, 퀵 도구, 통화, 지갑, SNS, 캘린더 등 다양한 기능을 제공하여 몰입감 있는 롤플레이 경험을 제공합니다.

## ✨ 특징

### 핵심 기능
- 🎭 **모듈화 설계**: 각 기능을 독립적으로 활성화/비활성화 가능
- 💾 **유연한 데이터 바인딩**: 채팅별 또는 캐릭터별 데이터 저장 선택
- 🎨 **팝업 기반 UI**: 깔끔한 오버레이 팝업으로 기능 제공
- 🤖 **AI 통합**: 슬래시 커맨드를 통한 자연스러운 AI 상호작용
- 📝 **컨텍스트 주입**: World Info 없이 프롬프트 직접 주입

### 제공 모듈 (Phase 2-4에서 구현 예정)
1. 😊 **이모티콘**: 커스텀 이모티콘 관리 및 전송
2. 📋 **NPC 연락처**: 주변 인물 등록 및 관계 관리
3. ⚡ **퀵 도구**: 퀵센드, 구분선, 읽씹, 사건생성, 음성메모
4. 📞 **통화 & 통화기록**: 통화 감지 및 기록 아카이브
5. 💰 **지갑 & 송금**: 커스텀 화폐 관리 및 송금 기능
6. 📸 **SNS 피드**: 랜덤 NPC 포스팅 및 댓글 시스템
7. 📅 **캘린더**: 1-30일 순환 캘린더 및 일정 관리

## 📥 설치 방법

### SillyTavern에 설치

1. SillyTavern 설치 디렉토리로 이동:
   ```bash
   cd /path/to/SillyTavern
   ```

2. 확장 디렉토리로 이동:
   ```bash
   cd public/scripts/extensions
   ```

3. 이 저장소 클론:
   ```bash
   git clone https://github.com/gulggu/STP.git st-lifesim
   ```

4. SillyTavern 재시작

5. 설정 → 확장 메뉴에서 "ST-LifeSim" 활성화

## 🎯 사용 방법

### 기본 설정

1. SillyTavern 설정 패널 열기
2. 확장 설정에서 "ST-LifeSim" 찾기
3. 전체 확장 활성화
4. 원하는 모듈 개별 활성화
5. "설정 저장" 클릭

### 데이터 바인딩

각 모듈의 데이터는 두 가지 방식으로 저장됩니다:

- **채팅별 저장** (기본): 현재 채팅에만 데이터 유지
- **캐릭터별 저장**: 같은 캐릭터면 모든 채팅에서 공유

모듈 설정에서 바인딩 방식을 변경할 수 있습니다.

## 🏗️ 개발 원칙

| 원칙 | 세부 사항 |
|------|-----------|
| **모듈화** | 각 기능은 독립된 모듈. 하나를 꺼도 다른 기능에 영향 없음 |
| **유지보수성** | 리팩토링 최우선. 공통 유틸 함수 철저히 분리 |
| **주석** | 초등학생도 이해할 수 있도록 모든 함수/로직에 한국어 주석 필수 |
| **ON/OFF** | 확장 전체 + 모듈별 개별 활성화/비활성화 |
| **바인딩** | 채팅별 기본 / 캐릭터별 선택 (항목 단위 전환 가능) |

## 📁 프로젝트 구조

```
st-lifesim/
├── index.js                  # 진입점. 모듈 로드 및 전체 ON/OFF 관리
├── manifest.json             # SillyTavern 확장 메타정보
├── style.css                 # 공통 스타일 (팝업 레이아웃, 오버레이 등)
├── settings.js               # 설정 저장/불러오기, 바인딩 분기
│
├── modules/                  # 각 기능 모듈 (Phase 2-4에서 구현)
│   ├── emoticon/             # 이모티콘 모듈
│   ├── contacts/             # NPC 연락처 모듈
│   ├── quick-tools/          # 퀵 도구 모듈
│   ├── call/                 # 통화 모듈
│   ├── wallet/               # 지갑 모듈
│   ├── sns/                  # SNS 모듈
│   └── calendar/             # 캘린더 모듈
│
└── utils/                    # 공통 유틸리티
    ├── storage.js            # 채팅별/캐릭터별 저장소 분기
    ├── context-inject.js     # 프롬프트 컨텍스트 주입
    ├── slash.js              # 슬래시 커맨드 래퍼
    ├── popup.js              # 팝업창 공통 컴포넌트
    └── ui.js                 # 토스트, 다이얼로그 등 공통 UI
```
